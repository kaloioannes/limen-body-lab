# 身体变化沙盒：证据与模型边界

资料核查日期：2026-10-30。本文面向虚构人物的交互模拟，不提供现实用药方案。文献支持某种变化的方向或大致时间，并不等于支持软件中的具体方程、参数或个体预测。

## 证据如何进入软件

- **文献观察**：明确来源、研究人群、随访时长和实际测量的终点。
- **机制示意**：用于解释吸收、清除、受体阻断及组织响应；相关系数如未经过拟合，必须称为作者设定。
- **无法可靠估计**：最终身高、精确罩杯、个体生育恢复、心理状态、骨折或血栓概率等，不输出貌似精确的数值。
- 阴影带如来自参数扰动，名称应为“假设变化范围”，不能称为“95%置信区间”或已验证的预测区间。

## 成人变化：可采用的时间锚点

下表对 [WPATH SOC8 表1](https://pmc.ncbi.nlm.nih.gov/articles/PMC9553112/) 的内容作概括。这些范围描述雌激素与降低睾酮方案的常见变化，不是各药物或任意剂量的独立效应估计，也不保证每个人发生相同变化。

| 特征 | 常见可察觉开始时间 | 较充分变化的参考时间 | 软件呈现 |
| --- | --- | --- | --- |
| 乳房组织 | 约3–6个月 | 约2–5年 | 缓慢、个体差异明显；不能等同精确罩杯 |
| 脂肪分布 | 约3–6个月 | 约2–5年 | 描绘分布趋势，不承诺具体腰臀围 |
| 肌肉量与力量 | 约3–6个月 | 约1–2年 | 分别展示；力量不直接按肌肉量同比例变化 |
| 皮肤出油与柔软度 | 约3–6个月 | 未知 | 定性响应，不编造皮肤检测值 |
| 终毛生长 | 约6–12个月 | 可能超过3年 | 有限减缓，不将已有胡须自动完全消除 |
| 自发勃起 | 约1–3个月 | 约3–6个月 | 定性提示，不预测个体性功能 |
| 睾丸体积 | 约3–6个月 | 变化较大 | 定性提示 |
| 头皮毛发 | 时间和程度不确定 | 不确定 | 不承诺毛囊恢复 |
| 已变低的声音 | 成人雌激素通常不会使其恢复 | — | 不自动升高音高 |

表中“较充分变化”不是生物学硬性截止时间。一个69名成人的三年前瞻性队列观察到乳房体积在整个随访中继续增长；胸围差较早趋于平台，却不等同乳房体积停止变化。因此不应在第24个月把所有乳房变化强制归零。[de Blok 等，2021](https://pubmed.ncbi.nlm.nih.gov/33206172/)

小样本长期队列在16名跨性别女性中观察到五年后骨骼肌体积下降，而力量未出现统计学显著变化；不能据此将某个固定百分比套用到所有虚构人物，也不应将体型动画包装成运动能力预测。[Lundberg 等，2025；2024在线发表](https://pubmed.ncbi.nlm.nih.gov/39604308/)

## 药物机制应分开处理

| 类别 | 机制层面需要区分的内容 | 不能从中推出什么 |
| --- | --- | --- |
| 雌二醇：口服、舌下、经皮、注射酯 | 输入、吸收和消退时间不同；有内分泌负反馈 | 同一毫克剂量等效；峰值越高外观变化越好 |
| 螺内酯 | 雄激素受体作用与其他药理作用；降低血清T程度不一 | 仅凭T值判断所有组织雄激素作用 |
| 醋酸环丙孕酮（CPA） | 孕激素样负反馈降低促性腺激素，也有受体拮抗 | 抑T更强必然使乳房长得更多 |
| 比卡鲁胺 | 以雄激素受体拮抗为主 | 将其模拟成直接等比例减少T产生 |
| GnRH激动剂 | 先有刺激、随后受体脱敏；抑制性腺轴 | 从第一秒起即时完全抑制；与所有拮抗剂完全相同 |
| 5α还原酶抑制剂 | 主要减少T向DHT的转化 | 全面消除T作用，或可替代所有其他抗雄机制 |
| 孕酮 | 单列为证据仍在发展的探索性干预 | 固定增加某一百分比的乳房体积 |

机制背景来自 [内分泌学会2017临床指南](https://academic.oup.com/jcem/article/102/11/3869/4157558)；细节需要结合具体制剂，不能对整类药物使用一套通用半衰期。

2025年发表的成人随机试验纳入63人，比较雌二醇联合两种抗雄药物，六个月时未发现乳房胸廓距离或估算乳房体积的显著组间差异。CPA组更容易降低T，仍不能由此推断其外观效果必然更强。[Angus 等，2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12086416/)

2024年比卡鲁胺病例系列只有24人，血清T差异较大；它支持区分“激素浓度”和“受体作用”，不建立经过验证的受体占有率公式，也不足以证明长期安全性。[Angus 等，2024](https://pubmed.ncbi.nlm.nih.gov/39691186/)

## 药代曲线的证据强度

10人的单次给药交叉研究发现，舌下与口服雌二醇的短时曲线不同；该结果不等于长期女性化更好。不能把单次8小时采样外推成所有剂量、所有间隔的已验证稳态曲线。[Doll 等，2022](https://pubmed.ncbi.nlm.nih.gov/34781041/)

2025年的注射雌二醇研究是562人的多中心回顾性研究，采血相对注射的时间影响结果。它适合检查剂量、间隔和采样时间应共同被记录；横断面数据不能直接充当每个个体的完整浓度时间序列。[Misakian 等，2025](https://pubmed.ncbi.nlm.nih.gov/39797602/)

UCSF 指南强调，充分抑制雄激素后，缺乏证据证明更高雌二醇水平带来额外女性化或乳房发育。该网页正文标注2016年发表且待修订，不能将其“缺乏注射研究”等旧描述视为2026年的全部证据。[UCSF 女性化治疗概览](https://transcare.ucsf.edu/guidelines/feminizing-hormone-therapy)

## 青春期模式：路径比较，避免伪造个体终点

青春期阶段与实际年龄应分开。GnRH抑制在出现青春期体征后的情境中讨论；成年人的抑制性腺轴作用也不能称为“把青春期倒退”。已经发生的变声、骨骼形态和终毛发育，需要与尚未发生的发育分开记录。[内分泌学会指南资源](https://www.endocrine.org/clinical-practice-guidelines/gender-dysphoria-gender-incongruence)

建议界面展示“内源性青春期进展可能受抑制”“未来变化取决于后续激素暴露”等定性事件。不能把阻断呈现为没有时间成本的身体冻结，也不能把整个干预过程标为完全可逆。

- 长期骨密度随访中，阻断期间年龄相关骨密度Z分数下降；后续雌激素治疗组的一些部位仍需关注。这不等于单凭持续时间即可计算个体骨密度或骨折风险。[van der Loos 等，2023](https://pubmed.ncbi.nlm.nih.gov/37902760/)
- 2024年青年骨密度研究也提示青春期抑制、体成分和骨量积累有关；研究设计和样本限制不支持一个通用的骨密度扣分公式。[Roy 等，2024](https://pubmed.ncbi.nlm.nih.gov/38562129/)
- 2024年丹麦生长队列涉及219名青少年，身高结果与骨龄及发育时机相关。该文有2026年勘误；没有逐一核对勘误与个体数据前，不应据摘要建立最终身高计算器。[Norup 等，2024及关联勘误](https://pubmed.ncbi.nlm.nih.gov/38627922/)

## 孕酮：不能把旧结论和初步结果混为一谈

Amsterdam UMC于2025-09-05发布90人试验的会议结果新闻，报告乳房发育方面的积极结果。它属于研究机构的初步结果发布，不等同可直接用于个体预测的完整参数集。软件可列为“初步研究信号”，不能设定固定增益。[研究机构公告](https://amsterdamumc.org/en/spotlight/addition-of-progesterone-leads-to-increased-breast-growth-for-transgender-women)

另一项随机安慰剂对照试验的2026年条目为研究方案，说明要如何研究，不是治疗效果结果；不能把方案论文当成有效性证据。[2026研究方案](https://pubmed.ncbi.nlm.nih.gov/42764919/)

## 必须通过的模型检查

1. **确定性与分支**：相同档案、历史和种子产生相同结果；从某个检查点分叉时，分叉前所有状态一致，未来事件不能改变过去。
2. **浓度与作用分离**：受体拮抗可改变作用指数，但不应被强制等同于血清T下降；5α还原酶路径单独处理DHT。
3. **给药与单位**：剂量量纲、制剂含义、间隔、开始与结束时刻均明确；不能把浓度mg/mL当单次剂量，也不能把经皮释放速率当口服剂量。
4. **药物切换**：停用后体内药物按清除过程消退；换药不能把旧药物储量即时删除；禁用事件不继续贡献新剂量。
5. **组织记忆**：乳房组织和已完成青春期变化不能随浓度下降立即归零；可逆变化也需要时间，不把所有终点做成同一指数函数。
6. **范围解释**：模型敏感性带明确为作者假设；其宽度不宣称反映真实发生概率。未知终点不输出小数值或百分比风险。
7. **与文献比较**：只在匹配人群、干预和测量终点下比较；测试符合指南时间窗口只叫“时间锚点检查”，不能叫临床验证或完成个体预测校准。
8. **外推提示**：超出可用随访、年龄或组合证据时可继续沙盒运行，但结果标明“机制外推”。人体渲染属于视觉映射，不是已验证的人体测量。
9. **未建模事项**：药物相互作用、疾病、生育恢复、精确风险、心理或性别认同等，若没有实装且验证，就明确为未建模；不生成最优用药建议。

模型参数与实际实现应在程序版本中另行记录。任何模型修订都应保留版本号，避免同一存档在无提示情况下产生不同结果。
