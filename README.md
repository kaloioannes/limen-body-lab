# 阈限 LIMEN · 身体变化实验室

一个可旋转人体、编辑干预时间表、拖动五年时间轴并创建实验分支的中文浏览器沙盒。默认本地计算和自动存档，无账户、无远程计算、无分析追踪。所有依赖随仓库提供，无运行时 CDN 请求。

**机制教育演示，未经临床校准。** 剂量和频率输入不构成现实用药指导，输出不能用于个人治疗或安全判断。不预测真实激素浓度、罩杯、最终身高、骨密度、生育恢复或风险概率。青春期路径仅定性展示。

## 使用

1. 定义虚构身体；种子用于固定假设的个体响应。
2. 编辑右侧干预，设置途径、剂量、间隔、开始与结束时间。
3. 拖动或播放 0–60 月时间轴。人体可拖动旋转、切换正侧背面和叠加基线。
4. 从当前时间分叉；分叉前的历史锁定。在原干预中选择“从分叉点调整”来改变后续。
5. 在分支对比页叠加曲线，最多保留 8 个方案；导出 JSON 存档或 CSV 示意数据。

自动存档属于当前浏览器。清理浏览器数据会移除存档；建议导出 JSON。导入会在确认后替换现有方案。测试时创建的虚构档案不随发布上传。

## 本地运行与测试

需要 Node.js 20.11 或更新版本，无需安装依赖。

```sh
node server.mjs
# 打开 http://127.0.0.1:4173
node --test tests/*.test.mjs
```

也可使用任意支持 JavaScript MIME 类型的静态 HTTP 服务器。ES modules 不能直接从 file:// 打开。

## 部署

通过 `.github/workflows/pages.yml` 自动运行模型测试，打包静态文件并发布 GitHub Pages。无需密钥。相对路径支持项目子目录。GitHub 仓库与网站公开；浏览器内存档不会进入仓库。
